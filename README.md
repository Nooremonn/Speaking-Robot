# Speaking-Robot

## Description

Robo Speaker is a simple Python program that converts text into speech. It uses the `pyttsx3` library 
to make your computer speak aloud whatever you type. You can interact with it by typing any text, and 
it will speak it out loud. To stop the program, simply type `bye`.

## Features

- Type any text and hear it spoken by your computer.
- Type `exit` to quit the program.

## Prerequisites

Before running the program, make sure you have **Python** and the necessary library installed.
1. **Python** (version 3.x) installed on your machine.
2. Install the `pyttsx3` library.
